# Moon School of Music: Homepage Redesign Demo

A clickable concept for a modern, conversion-focused homepage for Moon School of Music (Fairfax, VA).

**Live demo:** https://danielkim13.github.io/moon-school-redesign-demo/

## What's new compared with the current site

- **Hero that shows the outcome:** animated performance stage, a "Book a Free Trial Lesson" button and a recital video button
- **Sticky header**, plus a mobile bottom bar with Call and Book buttons
- **First-year timeline:** trial lesson, reading, first recital, then competitions
- **Instrument explorer:** pick an instrument to see ages, styles and a booking button for it
- **30-second matching quiz** that recommends an instrument and format and pre-fills the booking form
- **Teacher cards** with slots for short intro videos
- **Reviews** with a Google rating badge and specific quotes
- **Pricing** with a format switcher, per-lesson prices and "best for" labels
- **Upcoming events** (recitals, open house)
- **SEO basics:** meta description, Open Graph tags, a single H1

## Notes

This is a design demo. Teacher profiles, the recital video, event dates and some offer copy (free trial, 24-hour matching) are placeholders to confirm with the school. The booking form doesn't send anything.

## Run locally

Open `index.html` in a browser. There's no build step and no dependencies.
